## Product
One polished browser app preparing tomorrow: sleep timing from user target and next morning commitment; coffee routine from actual receipt timestamps (received timestamps explicitly not consumption); lunch conflict detection and safe gap suggestion; optional activity preparation without macro/medical prescriptions. Evidence shown per card. User explicitly selects actions and confirms before Calendar writes; Sheets stores preferences and action log. Real three-app requests required for live proof; demo uses clearly labeled synthetic local data. No false claims of live readiness or AI usage.

## Architecture
React 19 + TypeScript + Vite static deployment on GitHub Pages. Browser Google Identity Services OAuth token client, access token in memory only, no refresh token or client secret. Direct CORS REST for Gmail readonly, Calendar read + event writes, Sheets via drive.file scope to app-created workbook (prefer narrow; discuss if needs broader). Gemini key user-entered memory only, Google AI SDK or REST. AI can call bounded READ tools and propose explanations but cannot execute mutations; deterministic validated scheduling owns times/actions. No API keys shipped as VITE variables. Public OAuth client ID can be env or entered in setup. Provider interface in src/types.ts is shared authority; request changes from coordinator before altering.
